# Actual official environment

Ubuntu24.04, Python3.11.17, official bpy4.5.3 wheels and pinned generator requirements. The generator requirements describe Python packages; the worker additionally used official Ubuntu ffmpeg and EGL/X11 runtime packages listed in system-prerequisites.json. Ubuntu package sources used official HTTPS endpoints. No package source was patched. Exact successful command, pip package inventory, driver and renderer components are recorded in runtime-witness.json and case renderer-runtime.json.
